# TRIPPATROPPA

*Сходи за хлебом. Просто сходи за хлебом.*

Top-down шутер в духе жанра «вид сверху, один удар — одна клякса», нарисованный маслом. Всё процедурно пишется мазками прямо в браузере: асфальт, деревья, прохожие, галлюцинации, боссы. Холст, фактура, брызги краски остаются на «картине» уровня навсегда.

Герой — тревожный парень в горчичной толстовке, тапках и с авоськой. Психолог уговорила его впервые за четыре месяца выйти из дома и дойти до магазина. Дорогу подсвечивает охристая линия, вписанная прямо в живопись. По пути рассудок едет всё сильнее.

**Длина:** ~15 минут. **Концовок:** 6.

## Как играть
- Открыть `index.html` в браузере (сборка не нужна; работает и с диска, и с любого статического хостинга). `?nosw` — отключить офлайн-кэш при разработке.
- GitHub Pages: Settings → Pages → Source: **Deploy from a branch** → `master` / `(root)`. Сайт: https://kamazichyo.github.io/Trippatroppa/ — обновляется сам при каждом пуше в `master` (`.nojekyll` отключает обработку Jekyll).

| Действие | Клавиатура/мышь | Телефон |
|---|---|---|
| Идти | WASD / стрелки | левый палец |
| Целиться, бить, стрелять | мышь, ЛКМ (держать — лук натягивается) | правый палец |
| Рывок (короткая неуязвимость) | Пробел / Shift | ⇢ |
| Взять предмет | E | ✋ |
| Бросить предмет из рук | ПКМ / G | ➶ |
| Сменить оружие | Q / колесо / 1, 2 | ⇄ |
| Пауза | Esc | ❚❚ |

## На телефоне (iPhone/Android), бесплатно
Игра — веб-приложение (PWA): ставится на экран «Домой» и работает как обычное приложение, во весь экран и без сети после первого запуска.
1. Один раз включить GitHub Pages (см. выше). Игра будет на `https://kamazichyo.github.io/Trippatroppa/` — бесплатно для публичного репозитория.
2. iPhone: открыть адрес в **Safari** → «Поделиться» → **«На экран „Домой“»**. Запускать с иконки — так без панелей браузера и на весь экран.
3. Повернуть телефон горизонтально. Если нет звука — выключить беззвучный режим (переключатель сбоку).

Управление пальцами: левый палец — идти (рядом с врагом герой бьёт сам), правый — целиться и стрелять (прицел липнет к врагам), кнопки — рывок, взять, сменить, бросить.

## СДВГ-режим
- **Комбо** — убийства подряд множат очки и заряжают **фокус**; полный фокус — **ГИПЕРФОКУС**: время тянется, урон ×2, мир пересвечен.
- **Глюки** каждые ~20 секунд ломают мир на 12–15 с: «Всё огромное», «Всё крошечное», «Голубиный дождь», «Пол — это лава», «Дискотека в голове», «Всё плывёт», «Время тянется», «Кофеин», «Воображаемый друг» (дерётся за тебя), «Лица поменялись», «Дождь из краски».
- **Навязчивые задания**: «Убей 6 за 10 с», «Не пропусти ни удара», «Разбей 4 слова», «Поймай убегающую таблетку», «Не останавливайся», «Комбо ×8». Награда — рассудок и фокус.
- **Мутанты** с радужной аурой: вдвое крепче, роняют оружие и еду. **Мимики** — мусорные баки, которые отращивают зубы и ноги.
- **Превращения**: прохожие идут как обычные люди, а вблизи их лицо сползает и они превращаются в галлюцинацию. Деревья и окна открывают глаза, по земле текут мазки в духе «Звёздной ночи», с краёв экрана стекает краска, кадр плывёт волнами, у быстрых тварей двоятся силуэты, боссы трансформируются на второй фазе.

## Стадии
1. **Лёгкая нервозность** — двор у подъезда. Прохожие пихают в плечо, голуби, бабка с тележкой.
2. **Социофобия** — улица. Шептуны: их слова летят снарядами («ТЫ ВЫКЛЮЧИЛ УТЮГ?»), слова можно бить. Глаза-наблюдатели.
3. **Паранойя** — парк с фонтаном. Гопники, тени-собаки, курьеры. В конце галлюцинация дарит оружие на выбор.
4. **Галлюцинации** — квартал плывёт. Невидимые голоса (видны только круги звука, шёпот слышен в стерео и через синтез речи), плавленые люди, рты из асфальта, глаза в окнах.
5. **Шизофрения** — магазин «Продукты 24». Манекены (двигаются, только когда не смотришь), тележки, консервы-глаза на полках, колбаса-змея, кассирша-гидра.
6. **Мания величия** — три кассы ведут в разные финалы.

## Оружие
Подручное: кулаки, зонт, багет, бутылка (→ розочка), сковорода, труба, кирпич — всё ломается и всё можно швырнуть.
Дары галлюцинаций: радужный лук, бластер-фен, кисть-огнемёт, хлеб-бумеранг, атомный тостер, мольберт-пушка. Плюс перки: шапочка из фольги, нимб, рога, хлеба и рыбы, «ложись и накройся», палитра, третья кружка кофе.

## ИИ-режиссёр
`js/director.js` сам подбирает галлюцинации: волна нарастает → пик → откат → передышка. Следит за стрессом игрока (урон, кто рядом, сколько рассудка), за стилем (окопался — пришлёт обход и засаду со спины; стреляет издалека — быстрых; машет в упор — дальних), за разнообразием и тем, кто уже достал. Если тяжко — меньше танков, больше чая в передышке. Строит формации: клещи, засада, рой, хор шептунов по кругу. Интенсивность видна на ЭКГ в углу и слышна: музыка — это сердцебиение, темп которого растёт вместе с волной.

## Концовки
Какие три кассы откроются, зависит от выбранных даров и перков (у каждого свой «аспект»):

| Касса | Босс |
|---|---|
| Космос | Великий Психолог Космоса — планета-голова в очках с блокнотом |
| Рай | Всевышний (на приёме) — лицо в облаках и две руки |
| Ад | Дьявол, отдел договоров — «ПОДПИШИ ТУТ» |
| Галилея | Иисус (по воде) — хлеба делятся прямо в полёте, вино, рыбы, прощение |
| 1953 | Президент Рейнолдс (вымышленный) — мини-ядерки, «ложись и накройся» |
| Вена, 1907 | Абитуриент Адольф — ты приёмная комиссия, он кидается акварелями |

## Устройство
Чистый JS без сборки, классические `<script>`:

| Файл | Что внутри |
|---|---|
| `js/paint.js` | мазок-«щетина», SDF-формы, запекание спрайтов, фактура холста |
| `js/sprites.js` | все персонажи, оружие, боссы — нарисованы кодом |
| `js/world.js` | живописный фон кусками 512×512, декали, столкновения, поле путей |
| `js/levels.js` | двор → улица → парк → квартал → магазин → 6 арен |
| `js/entities.js` | оружие, игрок, 25 видов галлюцинаций, снаряды |
| `js/director.js` | ИИ-режиссёр волн |
| `js/chaos.js` | комбо, гиперфокус, глюки, задания, визуальные трипы |
| `sw.js`, `manifest.webmanifest`, `icons/` | установка на телефон и офлайн |
| `js/bosses.js` | кассирша и шесть финальных боссов |
| `js/render.js`, `js/game.js` | отрисовка, пост-эффекты (двоение, сдвиг цвета, виньетка), цикл, HUD |
| `js/audio.js` | синтез звуков, музыка-сердцебиение, голоса через Speech Synthesis |

Отладка через адрес: `?zone=0..4` — начать со стадии, `?boss=space|heaven|hell|jesus|atom|art` — сразу к боссу, `?god` — бессмертие, `?gift=bow` — выбрать дар.
