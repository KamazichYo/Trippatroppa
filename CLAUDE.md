# Trippatroppa — игра

Браузерный top-down шутер, «нарисованный маслом». Автор — художник Kamazich (Ереван). Общаться по-русски, прямо, без воды, мат норм.
Старое содержимое репозитория (арт-канал, игра «Градостроитель 90-х») — в истории git: `2387e67`, `a9e321f`.

## Принципы
- Без сборки и зависимостей: классические `<script>` в `index.html`, общий глобальный scope. Работает с `file://` и на GitHub Pages.
- Вся графика процедурная, мазками (`js/paint.js`): никаких растровых ассетов. Новый спрайт — через `bake()` + SDF-формы + `P()`; не рисовать плоские векторные фигуры там, где видно игроку.
- Движение органичное: пружины (`Spring`), `damp`, кадры «кипения» мазка (2–3 запечённых варианта на спрайт).
- Тексты двуязычные: `T('рус', 'eng')` или пары `['рус', 'eng']` + `tr()`. Русский — основной.
- Комментарии в коде — по-русски, коротко.
- Игра рассчитана на ~15 минут: длительность в основном задают `ZONES[*].dir` (`waves`, `budget`, `relax`) в `js/levels.js` и тайминги фаз в `js/director.js`.

## Проверка
Поднять статический сервер (`python3 -m http.server`) и прогнать Playwright (Chromium предустановлен). Удобные параметры адреса: `?zone=N`, `?boss=space|heaven|hell|jesus|atom|art`, `?god`, `?gift=bow`. Состояние игры доступно как `window.__game`.
